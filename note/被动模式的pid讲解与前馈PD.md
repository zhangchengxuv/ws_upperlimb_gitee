## 两层 PID 的职责差异
**内环（驱动器）**
输入：target_position / velocity

输出：电流/扭矩

频率：高（kHz 级）

作用：让电机“到位、稳住、快”

**外环**
输入：q_ref（正弦轨迹） 与 q（实际位置）

输出：q_cmd（给驱动的目标位置）

频率：低（100–200 Hz）

作用：修正轨迹跟踪误差（补滞后、补负载影响）


本质：
**内环管“执行”，外环管“目标怎么给得更合理”。**

### 1. 为什么看起来“重复”

因为两层都在用“误差 → 修正”的形式：

内环：e_motor = q_cmd - q_motor
外环：e = q_ref - q

所以直观上像是“PID 套 PID”。
但控制对象不同：

内环对象：电机 + 减速器
外环对象：整个机械臂 + 人体交互 + 轨迹误差
### 2. 什么时候外环是必要的

在你这个外骨骼场景里，外环是有意义的，原因：


- 轨迹是“时变的”（正弦）

    内环只知道“去 q_cmd”，但不知道轨迹在变：

    会有相位滞后
    幅值跟不上

    外环可以补这一点。

- 存在外部扰动

    系统有：
    人体作用力
    重力耦合
    结构摩擦

    内环只管执行，外环可以做补偿。



## 一个完整周期里 PID 是怎么跑的

以 joint4 为例，一次循环的顺序就是：

**第一步：读当前状态**
```cpp
q4 = state.position[IDX_J4];
```

拿到当前关节实际角度。

**第二步：生成参考轨迹**
```cpp
q_ref_j4 = q0_j4 + A4 * std::sin(w4 * t + phase4);
```

得到这一拍理论上应该到的位置。


```cpp
e4 = q_ref_j4 - q4;
```

看当前落后了多少。

**第四步：更新积分**
```cpp
e_int_j4 += e4 * dt;
```

累积长期误差。

**第五步：计算微分**
```
de4 = (e4 - e_prev_j4) / dt;
```

看误差变化得快不快。

**第六步：生成控制命令**
```
q_cmd_j4 = q_ref_j4 + Kp4 * e4 + Ki4 * e_int_j4 + Kd4 * de4;
```

得到修正后的目标位置。

**第七步：保存历史值**
```
e_prev_j4 = e4;
```

给下一拍使用。

**第八步：写入输出**
```
output.target_position[IDX_J4] = q_cmd_j4;
```

下发给底层位置模式执行。

## PD与前馈+PD的区别

### PD
首先`de4 = (e4 - e_prev_j4) / dt;`表示“误差的变化速度”（误差的导数）

在 PID 公式里：
```
Kd · de/dt
```
这一句是计算`de/dt`的。

每个变量的含义：
```cpp
e4          // 当前误差
e_prev_j4   // 上一时刻误差
dt          // 两次循环时间间隔
```
### 前馈+PD
由于路径已知其实已经知道目标速度为：`dq_ref = A*w*cos(wt)`

所以就可以写：`Kd * (dq_ref - dq)`

### 区别

**普通PD的D ≠ 真实速度信息，而是“误差变化的近似”**

#### 普通PD（误差微分）
```
de = (e - e_prev) / dt;
D = Kd * de;
```


展开一下：
```
e = q_ref - q

de = d(q_ref - q)/dt
   = dq_ref - dq
```

理论上它等价于：

```
dq_ref - dq
```
⚠️ 但问题在这里

没有直接用 dq_ref 和 dq，而是：**用“误差差分”去近似**

#### PD + 前馈
```
D = Kd * (dq_ref - dq);
```

这里是直接用真实物理量

**dq_ref：目标速度（已知）**

**dq：实际速度（测量）**


**核心区别一句话**

- 普通PD：用“误差变化”去猜速度差
- 前馈PD：直接用“真实速度差”
